* Criação e manipulação de tabelas
* Inserção e consulta de dados
* `SELECT`
* `WHERE`
* `ORDER BY`
* `GROUP BY`
* Funções de agregação
* `JOIN`
* Subconsultas
* Outros conceitos de SQL conforme avanço nos estudos
