# Análise de Dados — Empresa de Aluguel de Filmes

Projeto de análise de dados desenvolvido com o objetivo de aplicar conceitos de **SQL** em uma base de dados de uma empresa fictícia de aluguel de filmes.

O projeto foi desenvolvido como atividade prática a partir do conteúdo apresentado no canal **Hashtag Programação**, disponível no YouTube.

### 📚 Referência

Projeto desenvolvido com base na aula prática apresentada pela **Hashtag Programação**: [Projeto de Análise de Dados no MySQL](https://www.youtube.com/watch?v=hprufLQkS2M)
